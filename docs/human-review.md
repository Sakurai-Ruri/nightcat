### A-1. Git 提交署名是占位值

- [ ] 已改成我自己的 name / email

**现状**：`~/.git` 全局身份是空的，所以本仓库用了占位署名 `NightCat Dev <dev@localhost>`（当时你选的"先用占位"）。目前 4 个 commit 都是这个署名。

**为什么要你决定**：这决定了提交历史的署名，而且**已经提交的历史改了要重写**（`git rebase`/`filter-repo`），越早改越便宜。

**怎么做**：

```bash
cd nightcat
git config user.name "你的名字"
git config user.email "你的邮箱"

# 若要把已提交的 4 个 commit 一起改成新署名：
git rebase --root --exec 'git commit --amend --no-edit --reset-author'
```

### A-2. npm 缓存放在项目外层目录（对设计文档的偏离）

- [ ] 认可这个做法，或改成我更喜欢的方式

**现状**：你机器的 `~/.npm/_cacache` 里有 root 属主的文件（历史遗留），npm 写入时报 `EPERM`。标准解法是 `sudo chown -R 501:20 ~/.npm`，**我没有执行任何 sudo**，而是把缓存改到 `夜猫子神器/.npm-cache`（仓库外层，已被 `.gitignore` 排除）。代价：每次在 `nightcat/` 里装包要带 `--cache ../.npm-cache`。

**为什么需要你决定**：修 `~/.npm` 权限是一劳永逸的，但需要你的 sudo 密码，且会改动家目录——这属于"你的机器你的规则"。

**若选择修权限**（之后 npm 命令就不用再带 `--cache`）：

```bash
sudo chown -R 501:20 ~/.npm
```

另有一个独立问题：npm 源是 `registry.npmmirror.com`（淘宝镜像）。这是你原来的配置，我没动。用镜像装包更快，但**依赖内容与官方源存在理论差异**。若你在意供应链一致性，可切回官源。这个也请你确认一下是有意设置的。

### A-4. 用 localStorage 顶替 IndexedDB（对 D-002 的时间顺序调整）

- [ ] 认可先 localStorage、第 5 步再换 IndexedDB

**现状**：你要求作息不能硬编码，而"可编辑"就必须能持久化，否则刷新即丢。所以第 3 步就落地了 `StorageProvider` 接口，实现在 `src/providers/storage/localStorage.ts`。设计文档 D-002 原本写的是"V0 用 IndexedDB"。

**我的处理**：接口按 **IndexedDB 的异步形态**定义（`Promise` 返回值），所以第 5 步换实现时 UI 与领域层一行都不用改。理由已记入 D-013。

**为什么问你**：这毕竟偏离了原设计。如果你更希望"现在就一步到位上 IndexedDB"，那第 5 步会提前到现在——代价是多花时间在事务 API 上，收益是少一次替换。

## D. 技术债与已知局限（不需要你现在做，但要知道它们存在）

- **夏令时**：`elapsedMinutes` 按本地时间字段直接相减，不补偿 DST 跳变，切换日可能差 1 小时。已在测试中显式钉住，见 D-010。
- **连续熬夜**：超过 24 小时不睡不会切分个人日。已在测试中记录。
- **`sleepTimeOfDay` 的 0 值歧义**：09:00 起床 + 9 小时睡眠时返回 `0`，无法区分"00:00"与"无值"。V0 不使用它的返回值，已加注释。
- **测试文件的三处重复**：`src/**/*.test.ts` 这个模式同时写在 `package.json`、`tsconfig.test.json`、`tsconfig.app.json` 三处，必须保持一致。见 D-012。
- **Open-Meteo 免费额度未实测**：第 4 步实现时确认（本项目用量每天数次，除非被滥用不会触及）。
- **极昼/极夜**：`sunrise`/`sunset` 可能缺失，第 4 步需能表达"当日无日出"而不崩。见 D-010。
- **没有浏览器测试方案**：D-009 只覆盖纯函数。第 3 步的组件逻辑已尽量挤进 `format.ts` / `clockView.ts` 这两个可测模块，但 React 组件本身仍无自动化验证。
